# Final Assembly Rules

Assemble only validated sections and verified charts.

The final editor may:

- draft an evidence-grounded executive summary and conclusion;
- propose section ordering allowed by the standard structure;
- identify repetition or contradiction;
- add short transitions;
- request targeted repair of a failed section.

The final editor must not freely rewrite validated analytical sections, alter
their numbers, add evidence, or change chart data. Code performs deterministic
assembly of approved section bodies and chart placements.

Run whole-report checks after assembly:

- required structure and word range;
- numeric grounding and units;
- section and chart reference integrity;
- cross-section period and value consistency;
- unsupported causal language;
- duplicate or contradictory claims.

If final editorial content fails validation, fall back to deterministic
assembly of the already approved sections.
