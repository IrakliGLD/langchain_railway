# Standard Report Structure

A standard ENAI report targets 900–1,400 words and contains five to eight
sections. The required order is:

1. **Executive summary** — principal findings and answer, normally 100–160 words.
2. **Scope and evidence** — period, metrics, sources, method, and boundaries,
   normally 80–140 words.
3. **Intent-specific core analysis** — the main evidence-backed analysis,
   normally 350–600 words. Its semantic kind is selected from authoritative
   question analysis:
   - general → key findings and analysis;
   - trend → trend analysis;
   - comparison → comparative analysis;
   - composition → composition analysis;
   - driver analysis → driver analysis;
   - forecast → forecast and outlook;
   - scenario → scenario analysis;
   - knowledge → context and framework.
4. **Additional analysis** — zero to three focused subsections when the evidence
   supports distinct topics.
5. **Implications** — optional; evidence-consistent implications without
   overstating causality.
6. **Limitations and data gaps** — material evidence, coverage, and methodology
   limitations, normally 80–150 words.
7. **Conclusion** — concise supported answer, normally 60–120 words.

Executive summary, scope and evidence, the selected intent-specific core,
limitations, and conclusion are mandatory. Additional analysis and implications
are optional. Do not add sections merely to meet a word target.

Write report and section titles and objectives in the planning context's answer
language. The canonical English request objective defines semantic scope; it
does not change the required output language.

Charts are placed inside the section they support. A chart is not a separate
report section. Use no more than three charts in a standard report.
